🚀 Mit’s VPN — Beta 1.5

• Добавили экран обновлений: проверка новой версии, список изменений и скачивание APK прямо в приложении.
• Перед установкой проверяются целостность APK, пакет, номер версии и совпадение подписи. Установку подтверждает Android.
• Подготовили постоянную подпись для следующих версий: обновления поверх Beta сохраняют профили и настройки.
• Добавили импорт клиентского VPN-профиля по QR-коду. Камера открывается по нажатию; добавление требует подтверждения.
• Профилям можно задавать свои названия.
• Порядок резервных профилей теперь можно менять стрелками.

Маршрутизация по умолчанию сохранена: российские домены/адреса из используемых списков и локальная сеть — напрямую, остальной трафик — через VPN при подключении.

⚠️ При переходе с Alpha может понадобиться одна переустановка из-за смены подписи. Перед удалением сохраните исходную ссылку или файл профиля. Экспорт профилей не добавляли.
