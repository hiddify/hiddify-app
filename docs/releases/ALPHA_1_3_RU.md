## Причина и границы проверки

В предоставленном тестовом экспорте обнаружены два дополнительных несовместимых
с Alpha 1.2 поля: DNS с подстановками и PersistentKeepalive `25-35`. Ошибка DNS
возникает раньше проверки keepalive; исправление только одного поля недостаточно.
Остальные параметры из Alpha 1.2 уже поддерживаются. Полный клиентский ключ,
адрес сервера и исходный экспорт в Git и CI не добавлялись.

Схема `AwgPeerOptions` закреплённого hiddify-sing-box
`fda14fcdb55a08284b210657bdd8b6175e817699` объявляет
`PersistentKeepaliveInterval` как `uint16`; диапазон там сохранить нельзя.
Среднее значение выбирается один раз при импорте; поля маскировки AWG, включая
отдельный `KeepaliveTimeout`, сохраняются без такого преобразования.
DNS из профиля, включая две известные подстановки, не переопределяет DNS Mit.
Другие неизвестные подстановки и недопустимые диапазоны отклоняются.

Синтетический fixture воспроизводит сочетание проблемных полей исходного
экспорта; ключи, адрес и байты пакетного шаблона заменены тестовыми значениями.

Дополнительно исходный пользовательский ключ распакован только локально.
Его поля проверены независимым диагностическим преобразованием; сформированный
endpoint принят CLI draft-ядра v5.4.0 / sing-box 1.15.0-alpha.13, revision
`b097daadd89d2b62e30c0f4353f55a973118514c` (`parse` и `CheckConfig`, код 0).
В выходе сверено сохранение клиентских ключей, PSK, всех параметров AWG и
keepalive=30. Это проверка native-конфигурации, не выполнение Dart-импортёра
на исходном ключе и не проверка handshake с сервером.
